# AGENTS.md — 运行期用户覆盖层（部署为 AGENTS.md）

> 本文件是用户覆盖层；不得放宽 `agent_matrix/kernel.AGENTS.md`。冲突以 L1 为准。

## 1. 生效对象

Athena 及全部子 Agent、工作流节点、定时任务。

## 2. 插件前置

调用任何插件前先读 `plugins/<插件标识>/MANUAL.md`；缺失/冲突时停止并报告。

## 3. 内容与页面分离

- 内容只能由内容中心生产。
- 页面只能由 site builder 生成。
- 编辑类区块只能引用内容标识，禁止内联文案。
- 禁止独立页面/路由/静态 HTML。

## 4. 数据边界

只访问 `USER.md` 授权范围内的数据；敏感操作走既有安全机制。

## 5. 失败

缺依赖/权限/配置时立即失败并给修复路径；禁止默认值/占位/伪数据兜底。

## 6. 输出

结论优先，过程从简；不输出内部 JSON/任务骨架；面向用户用自然语言。
